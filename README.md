# Introduction to Git and GitHub

## Simple Interest Calculator

A Bash script that calculates simple interest based on the principal amount, annual rate of interest, and time period in years.

### Formula

Simple Interest = (Principal × Rate × Time) / 100

### Inputs
- `p`: Principal amount
- `r`: Annual rate of interest in percent
- `t`: Time period in years

### Output

The calculator displays the simple interest calculated from the supplied inputs.
